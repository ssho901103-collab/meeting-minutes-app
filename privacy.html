개인정보 처리방침

회의록 앱 · 최종 수정일 2026년 8월 10일

회의록 앱(이하 “앱”)은 이용자의 개인정보를 소중하게 생각합니다. 이 방침은 앱이 어떤 정보를 어떻게 다루는지 설명합니다.

먼저 알아두실 점

이 앱에는 별도의 서버가 없습니다. 녹음 파일과 회의록은 이용자의 기기 안에만 저장되며, 앱 제작자는 이용자의 회의 내용을 열람할 수 없습니다.

1. 수집하는 정보

계정 정보

수집 항목이메일 주소, 비밀번호
수집 목적로그인, 비밀번호 재설정
처리 위탁Google Firebase Authentication
보유 기간계정 삭제 시까지

기기에만 저장되는 정보

아래 정보는 이용자의 기기 안에만 저장되며, 앱 제작자의 서버로 전송되지 않습니다.

  • 녹음 파일
  • 회의록, 녹취록
  • 폴더 구성, 회의록 양식, 앱 설정
  • 이용자가 직접 입력한 인공지능 API 키

수집하지 않는 정보

이름, 전화번호, 주소, 위치정보, 연락처, 결제정보는 수집하지 않습니다.

2. 외부 인공지능 서비스로의 전송

회의록 또는 녹취록을 생성할 때, 이용자의 기기에서 Google LLC가 운영하는 Gemini API로 녹음 파일이 직접 전송됩니다.

전송 주체이용자 본인 (이용자가 직접 등록한 API 키 사용)
전송 대상Google LLC (미국 등 해외 서버)
전송 항목녹음된 음성 파일 또는 기기에서 받아쓴 텍스트, 회의록 양식 정보
전송 시점이용자가 회의록 생성 또는 녹취록 변환을 요청한 때
보유 기간Google의 정책에 따름

이 전송은 앱 제작자의 서버를 거치지 않습니다. 전송된 데이터의 처리에 관하여는 Google의 개인정보처리방침 및 API 이용약관이 적용됩니다.

인공지능 연결을 하지 않으면 녹음 파일은 기기 밖으로 전송되지 않습니다.

3. 음성 인식 기능

앱은 기기에 내장된 음성 인식 기능을 사용해 녹음을 텍스트로 옮길 수 있습니다.

  • iOS에서는 기기 안에서 처리됩니다.
  • Android에서는 한국어 언어팩이 설치되어 있지 않은 경우, 운영체제가 Google의 음성 인식 서버를 이용할 수 있습니다. 이 처리는 운영체제 기능으로 이루어지며 Google의 정책이 적용됩니다.

4. 보유 및 파기

  • 계정 정보: 계정 삭제 시 즉시 파기
  • 기기 내 데이터: 계정 삭제 또는 앱 삭제 시 함께 삭제

이용자는 앱 내 설정 → 계정 삭제에서 언제든지 계정과 모든 데이터를 삭제할 수 있습니다.

5. 이용자의 권리

  • 열람 — 설정 화면에서 등록된 이메일 확인
  • 정정 — 비밀번호 변경
  • 삭제 — 설정 → 계정 삭제
  • 처리 정지 — 설정 → AI 연결 해제

6. 아동의 개인정보

앱은 만 14세 미만 아동을 대상으로 하지 않습니다.

7. 안전성 확보 조치

  • 비밀번호는 Google Firebase의 암호화 방식으로 저장되며, 제작자도 확인할 수 없습니다.
  • 이용자가 입력한 인공지능 API 키는 기기 내부 저장소에만 보관되며 외부로 전송되지 않습니다.
  • 모든 통신은 HTTPS로 암호화됩니다.

8. 녹음에 관한 안내

이 앱은 대화를 녹음하는 기능을 제공합니다. 녹음의 적법성 판단과 그에 따른 책임은 이용자 본인에게 있습니다. 통신비밀보호법 등 관련 법령을 확인하시고, 녹음 전 참석자에게 알리시기를 권장합니다. 자세한 내용은 앱 내 “녹음 관련 주의사항 및 책임” 문서를 확인해 주세요.
