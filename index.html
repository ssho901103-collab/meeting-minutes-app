회의록

녹음과 받아쓰기를 바탕으로 내 양식에 맞는 회의록을 작성합니다.

이런 앱입니다

  • 회의를 녹음하면 AI가 구조화된 한국어 회의록으로 정리합니다.
  • 참석자, 안건, 논의 내용, 결정사항, 할 일을 항목별로 나눠 보여줍니다.
  • 샘플이 없으면 기본 회의록 양식을 사용하고, 등록한 샘플은 문체와 항목 구성의 참고 자료로 사용합니다. AI 모델을 별도로 학습시키지는 않습니다.
  • 고객사·프로젝트별 폴더로 정리하고, 내용까지 검색할 수 있습니다.

개인정보에 대해

  • 녹음과 회의록은 기기에 보관하며 앱 운영자의 서버에는 저장하지 않습니다. AI·음성 인식 기능을 사용하면 동의한 외부 업체로 처리에 필요한 자료가 전송됩니다.
  • 제작자는 이용자의 회의 내용을 볼 수 없습니다.
  • 회의록 생성에는 OpenAI·Gemini·Claude 중 선택한 업체의 API 키가 필요합니다. API 사용 요금·한도는 해당 업체와 이용자 계정 조건에 따릅니다.
  • 가입 없이 기기에서 사용할 수 있습니다. 선택 가입 시 Firebase가 계정 정보를 처리하며, 로그인만으로 기기 간 자료가 동기화되지는 않습니다.
  • 앱 업데이트 확인 시 Expo가 설치 식별자·IP·버전·실행 오류 정보를 처리할 수 있습니다. 자세한 항목과 보유 조건은 개인정보 처리방침에서 확인할 수 있습니다.
